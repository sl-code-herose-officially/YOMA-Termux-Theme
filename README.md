# YOMA Termux Theme

A simple, lightweight Termux customization tool by YOMA.

## Features

- Interactive theme selector
- YOMA Cyber theme
- Cyberpunk theme
- Matrix theme
- Minimal theme
- Automatic `.bashrc` backup
- Reset option
- Uninstall option
- No root required

## Install

```bash
git clone https://github.com/YOUR_USERNAME/YOMA-Termux-Theme.git
cd YOMA-Termux-Theme
bash install.sh
```

## Update

```bash
cd YOMA-Termux-Theme
git pull
bash install.sh
```

## Uninstall

From the menu choose:

```text
[6] Uninstall
```

Or run:

```bash
bash uninstall.sh
```

## Notes

This project changes shell prompt and Termux color/property files. It does not require root and does not install external hacking tools.
